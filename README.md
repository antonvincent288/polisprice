# ПолисПрайс — ОСАГО 2026 по коэффициентам ЦБ (трек А)

Astro (база — шаблон AstroWind) + собственные страницы. Сборка: `npm run build`, вывод в `dist/`.

## Структура
- `src/data/osago_coefficients_2026.json` — верифицированные коэффициенты (Указание ЦБ 7204-У, ред. 04.05.2026, проверено 05.11.2026 по Garant). Единственный источник данных для всех страниц и калькулятора.
- `src/pages/index.astro` — главная.
- `src/pages/osago/kalkulyator.astro` — калькулятор (ТБ × КТ × КБМ × КВС × КО × КМ × КС; диапазон по коридору ТБ).
- `src/pages/osago/koeffitsienty.astro` — справочник: КТ (все зоны), КМ, КВС, КО, КС, КП, КБМ.
- `src/pages/osago/tarify.astro` — базовые тарифы по категориям ТС.
- `src/pages/osago/moscow.astro` — GEO-страница «ОСАГО в Москве» (КТ 1,8); примеры считаются на этапе сборки из JSON.
- `src/layouts/Base.astro` — общий layout (шапка, футер, мета).

## Добавление GEO-страниц
Новая страница региона = копия `moscow.astro` с заменой региона и КТ. Все числа считаются из JSON — руками ничего не считать и не вписывать.

## Деплой (Cloudflare Pages)
1. Push в GitHub. 2. Cloudflare Pages → Create project → подключить репозиторий → build command `npm run build`, output `dist`. 3. После привязки домена обновить `site` в `src/config.yaml` (влияет на sitemap и canonical).

## Комплаенс
- Даты актуальности коэффициентов указаны на каждой странице.
- До подключения CPA-ссылок: добавить `rel="sponsored"`, маркировку рекламы (ЕРИР/ОРД).
- КТ по спорным регионам (см. `_meta.flag` в JSON) сверить с cbr.ru перед публикацией.
