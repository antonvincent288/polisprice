**Дата:** 08.11.2026. Основание: разбор pampadu.ru/webtools, GitHub-поиск, проверки реестров.

## РЕШЕНИЕ: виджет Пампаду — основной; Полис.онлайн — тестовый второй; Getpolis — стоп

| Платформа | Ставка КВ | Выплаты | Формат интеграции | Вердикт |
|---|---|---|---|---|
| **Пампаду** | как в ЛК (те же, что при ручной продаже) | самозанятым — моментально | JS-сниппет/iframe из ЛК + API + White Label | ✅ ОСНОВНОЙ |
| Полис.онлайн | 10–60% (в зависимости от продукта) | мгновенно | готовый код виджета из ЛК | ✅ ТЕСТ-второй |
| Agenters | до 25–27% | каждую пятницу | виджет на сайт | резерв |
| Getpolis | до 35% | до 24 ч | виджет | ⚠️ ПАУЗА: в 2026 в реорганизации (форма преобразования), уставный капитал понижен 500 тыс.→50 тыс. ₽ (по данным реестра) — пока монополию не даём |

Почему Пампаду основным виджетом, а не новым партнёром:
- одна регистрация закрывает и CPA-слоты, и виджет, и API — один кабинет, одна сверка, один eCPC-учёт;
- комиссия через виджет ровно та же, что при оформлении в личном кабинете (без снижений);
- кейс негативных отзывов на Пампаду — в основном по финансовым/HR-офферам; по страховым оценка стабильно хорошая;
- технически: сайт на GitHub Pages — статика; виджет Пампаду встраивается JS-сниппетом (браузерный), а вот коробочные PHP-виджеты (b2bpolis и т.п.) на GitHub Pages физически не запустятся — отсеяны.

## КУДА ВСТАВИТЬ ВИДЖЕТ ПОСЛЕ РЕГИСТРАЦИИ (делаю я)

| Зона сайта | Что ставим |
|---|---|
| Все GEO-страницы (190 городов + 190 моделей×регионов) | виджет Пампаду (JS-сниппет) — заглушка уже предусмотрена в шаблоне |
| Калькулятор (osago/kalkulyator) | виджет Пампаду |

Отслеживание: в Метрике цели на клики по виджету; каждая страница — свой sub_id (это даёт точный eCPC по типам страниц; через квартал — перераспределение офферов по фактическому eCPC).

## ОРИЕНТИРЫ ПО РСЯ (для понимания масштаба)

- Кейс веб-мастера (vc.ru, 2026): 597 визитов/день → ~142 ₽/день на чистой РСЯ (≈0,24 ₽/визит). Финансовая тематика дороже среднего.
- Правило из отрасли (Хабр, монетизаторы): не полагаться на одну сеть, смотреть итоговую выручку. У нас РСЯ — фоновая касса, основная — CPA/виджеты (там eCPC 10–30 ₽ — на порядок выше баннерного).

## РИСКИ И КОНТРОЛЬ

- Пампаду: споры по выплатам случаются (83 отзыва на Partnerkin: в основном хвалят, но есть кейсы «лид не отобразился», сдвиг сверок на несколько дней). Контроль: подача только через /go/* redirect-слой + суб_ид на каждую страницу; при задержке выплат > 3 дней — стоп-слоты (runbook в ROADMAP).
- ФЗ-347 маркировка: у Пампаду и РСЯ маркировка автоматическая; при добавлении прямых рекламодателей — маркировка наша.
