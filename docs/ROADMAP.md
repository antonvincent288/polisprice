## 0a. ГРАНДИОЗНАЯ ЦЕЛЬ (манифест проекта)

> **ПолисПрайс — трафик-пылесос и конвейер денег.**

**Трафик-пылесос** = машина, которая засасывает поисковый спрос целиком, не оставляя конкурентам ниши:
- 1649+ страниц закрывают ВСЁ: словарь коэффициентов, 44 гайда, 191 город, PAA-вопросы, llms.txt для ИИ-агентов;
- принцип «если человек спросил про ОСАГО хоть что-то — он попал к нам»;
- фактура всегда свежее конкурентов (7204-У, сверка с cbr.ru по регламенту) — мы не опаздываем, конкуренты отстают;
- каждая новая страница повышает воронку, а не просто увеличивает счётчик.

**Конвейер денег** = монетизационная линия, где каждый посетитель проходит через каскад касс:
1. Касса №1: ОСАГО-офферы (Пампаду/САЛИД) — калькулятор, GEO, гайды;
2. Касса №2: проверка авто (Автокод/Автотека) — б/у-трафик, лучший eCPC;
3. Касса №3: КАСКО — горячий апсейл после расчёта ОСАГО;
4. Касса №4: ВЗР (Черехапа) — второй контур;
5. Касса №5: реферальный слой (агенты — 50 ₽/полис + 4 000 ₽/агент) — пассивная пропеллерная тяга;
6. Касса №6 (мес 6+): email-база и напоминания о продлении — деньги возвращаются сами, ежегодно.

**Место в плане 5 млн ₽/мес:** ПолисПрайс сам по себе — пассивный фронт с потолком ~0,5–0,6 млн ₽/мес на один сайт (симуляция 05.11 подтверждена). Его настоящее значение: это **первый работающий экземпляр конвейера**, который после выхода на крейсерский режим **тиражируется**: тот же движок (AstroWind + аудит + GEO-матрица + llms.txt + партнёрские слоты) клонируется на следующую вертикаль. Один сайт — проверка конвейера; конвейер, а не сайт, — машина на 5 млн.

**Критерий успеха проекта (жёсткий):** к месяцу 12 — трафик 2000+ визитов/сутки и доход ≥150 тыс ₽/мес в базовом сценарии; иначе разбираем на узкие места (см. матрицу рисков) и исправляем, не выбрасывая актив.

## 5. ПРОТОКОЛЫ РЕАГИРОВАНИЯ (runbooks)

- **Партнёр не платит 7+ дней** → стоп слотов этого партнёра (redirect на второго), письмо афф-менеджеру, арбитраж по отзывам — не продолжать лить.
- **Апдейт поисковика, трафик −30%+ за 3 дня** → заморозить контент-батчи на 2 недели, вносить только фактурные фиксы; после стабилизации — ретро.
- **Ошибка 500/404 на проде** → немедленный rollback CI, аудит, пост-мортем в этот файл.
- **Оффер отключён** → авто-редирект САЛИД + проверка метрик второго партнёра; если оба молчат — резервный (Инсапп/Полис 812).
- **ФАС/жалоба** → снять слот с ero-токеном? Не снимать, а добавить erid немедленно; если не выдан — снять слот до оформления.
